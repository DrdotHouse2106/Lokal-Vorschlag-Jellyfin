# Welten-Liste – umgezogen

Die Welten-Liste wird jetzt im eigenen Repository **[Jellyfin-Welten](https://github.com/DrdotHouse2106/Jellyfin-Welten)** gepflegt und dort wöchentlich aus TMDB aktualisiert. Von Hand ergänzte Titel und Ausschlüsse stehen dort in `regeln.json`.

Ab Local Recommendations 12.12.0 lädt das Plugin die Liste von dort (`https://raw.githubusercontent.com/DrdotHouse2106/Jellyfin-Welten/main/welten.json`); eingestellte Adressen auf diese alte Datei werden automatisch umgestellt. Die Datei `welten.json` hier bleibt nur für ältere Plugin-Versionen (12.11.x) stehen und wird nicht mehr aktualisiert.
